PDF 저장 방법

‘PDF 저장’을 눌렀는데 인쇄 창이 열렸나요? 정상입니다.
인쇄 창의 ‘대상’을 ‘PDF로 저장’으로 바꾸세요.
프린터가 없어도 PDF 파일을 저장할 수 있습니다.
  1. 과목 페이지에서 학번·이름을 입력하고 빈칸 활동을 완료합니다.
  2. ‘완료 목록·출력’에서 완료한 문항과 출력 범위를 확인합니다.
  3. ‘인쇄 / PDF로 저장’을 누릅니다.
  4. PC 크롬 인쇄 창에서 ‘대상’ → ‘PDF로 저장’을 선택합니다.
  5. 미리 보기에서 학번·이름·문항·작성한 답을 확인합니다.
  6. ‘저장’을 누르고 파일 이름과 저장할 폴더를 정합니다.
    예: 10월_국어_오답정리_10101_홍길동.pdf
  7. 저장된 PDF를 열어 확인하고 선생님이 안내한 곳에 제출합니다.

이 안내는 PC 크롬 기준입니다. 각 과목 페이지의 ‘PDF 저장 방법’에서도 확인할 수 있습니다.

완료 확인 후 저장하세요.빈칸을 모두 맞히고 완료한 문항을 출력합니다. 답을 수정했다면 정답 확인을 다시 눌러 주세요.

제출은 별도로 해야 합니다.작성 기록은 과목별로 해당 기기·브라우저에 저장되며, 선생님께 자동 전송되거나 다른 기기와 자동 연동되지 않습니다.
